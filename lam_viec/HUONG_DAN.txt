THIET BI KHONG CO TRINH DUYET (dong ho, mach vi dieu khien...)
--------------------------------------------------------------------
phat-vi-tri-tool.html chi la MOT cach de gui vi tri - danh cho bat ky
thiet bi nao mo duoc trang web (dien thoai, may tinh bang, dong ho
thong minh co trinh duyet nhu WearOS/Chrome...). Nhung khong phai
thiet bi phat nao cung co trinh duyet: mach vi dieu khien nho (ESP32,
ESP8266 gan module GPS NEO-6M...), bo dinh vi GPS/GPRS re tien
(SIM800L, A9G...), hay 1 script chay tren may tinh nhung deu KHONG
chay duoc trang HTML/JS.

Vi vay server co them 1 API HTTP THUAN (khong can WebSocket, khong
can trinh duyet, khong can giu ket noi lien tuc) de nhung thiet bi
nay ban 1 request moi khi co toa do moi:

  GET  http://<dia-chi-server>/api/pos?room=MA_PHONG&deviceId=ID_RIENG&name=Ten&lat=..&lon=..&ts=..&sig=..&accuracy=..&speed=..&heading=..
  POST http://<dia-chi-server>/api/pos     (Content-Type: application/json)
       { "room": "MA_PHONG", "deviceId": "ID_RIENG", "name": "Ten",
         "lat": 21.03, "lon": 105.85, "ts": 1234567890, "sig": "...",
         "accuracy": 10, "speed": 0, "heading": 0 }

  Bat buoc: room, deviceId, lat, lon (lat/lon phai la so), ts, sig.
  Tuy chon: name (mac dinh "Thiet bi <6 ky tu dau cua deviceId>"),
  accuracy (met), speed (m/s), heading (do, 0-360).

  (2026-08-07) ts + sig BAT BUOC - xem muc "XAC THUC HMAC" ngay duoi
  day. Thieu hoac sai 1 trong 2 -> 401 {"ok":false,"error":"..."}.

  Tra ve JSON: {"ok":true} khi thanh cong, {"ok":true,"throttled":true}
  neu gui qua nhanh (bi bo qua, xem muc rate-limit ben duoi) - van la
  200, khong can code xu ly loi phuc tap. Loi du lieu (thieu
  room/deviceId, lat/lon khong hop le...) tra ve 400 kem {"ok":false,
  "error":"..."}. Loi chu ky/het han tra ve 401.

  deviceId nen dat CO DINH cho tung thiet bi vat ly (vd ghi san trong
  code nap vao mach) de "thu" nhan ra day la cung 1 thiet bi qua cac
  lan gui.

XAC THUC HMAC (bat buoc tu 2026-08-07):
   ts = so giay Unix hien tai (thiet bi phai co gio dung - dong bo qua
        NTP, xem syncTime() trong GpsPosSender.ino - hoac RTC that).
   sig = HMAC-SHA256 hex, key la API_SECRET (xem BUOC 0), thong diep ky
         la chuoi ghep dung thu tu sau, noi bang ky tu "|":
           room + "|" + deviceId + "|" + ts + "|" + lat + "|" + lon
         Dung DUNG chuoi da gui (khong format lai so) - vi du lat gui
         "21.030000" thi phai ky dung chuoi "21.030000", khong phai so
         21.03 da lam tron/parse lai, neu khong sig se sai.
   Server tu choi neu |gio_server - ts| > 5 phut (MAX_CLOCK_SKEW_MS
   trong server.js) - chan viec ghi lai 1 request cu roi gui lai
   (replay attack).

Vi du thu nhanh bang curl + node (thay <server> va <API_SECRET> bang
gia tri that; script node tinh sig roi in ra URL day du de dan vao curl):

  node -e "
    const c=require('crypto'),room='ABC123',deviceId='esp32-01',
    lat='21.030000',lon='105.850000',ts=Math.floor(Date.now()/1000);
    const sig=c.createHmac('sha256',process.env.API_SECRET)
      .update(room+'|'+deviceId+'|'+ts+'|'+lat+'|'+lon).digest('hex');
    console.log('http://<server>/api/pos?room='+room+'&deviceId='+deviceId+
      '&lat='+lat+'&lon='+lon+'&ts='+ts+'&sig='+sig);
  "
  # roi: curl "<url in ra o tren>"

Vi du minh hoa day du (co ky HMAC + dong bo NTP) cho mach ESP32 + GPS:
xem GpsPosSender/GpsPosSender.ino (da chay tren khung, chi can dien
WIFI_SSID/WIFI_PASSWORD/API_SECRET trong secrets.h roi nap sketch).

LUU Y RATE-LIMIT DUNG CHUNG: server chi nhan toi da ~1 vi tri/giay cho
MOI deviceId, tinh chung ca duong WebSocket lan HTTP (gui ca 2 kieu
cho cung 1 deviceId van bi tinh chung 1 gioi han). Gui qua nhanh se
bi lang le bo qua (throttled:true), khong phai loi.

CHUAN BI (1 lan duy nhat):
  cd lam_viec, npm install (cai serialport de doc cong COM - can internet
  LUC NAY, hoan toan KHONG can internet khi chay ve sau).

CACH DUNG - bam 2 lan (hoac "Run") 1 trong 2 file .bat sau, MOI file tu lam
HET moi buoc (khoi dong server + mo trinh duyet + chay script doc SMS),
khong can tu go lenh node nao ca:

  CACH 1 - nhan-sms-tu-dong-esp32-usb.bat
    Dung khi co bo SmsReceiverUSB (ESP32+A7680C) cam USB vao may tinh nay:
    - Nap sketch SmsReceiverUSB/SmsReceiverUSB.ino vao ESP32 (wiring
      A7680C giong het SmsReceiver.ino) - sketch nay KHONG can WiFi/
      secrets.h, chi in "TOADO|deviceId|ten|lat|lon" ra cong USB.
    - Cam ESP32 vao may tinh bang day USB (thay vi de o noi co WiFi nhu
      SmsReceiver.ino goc).
    - Bam file .bat, no se hoi cong COM (vd COM5) - khong biet thi de
      trong roi Enter, no se in danh sach cong dang co de ban chon, roi
      chay lai file .bat va go dung ten cong do.

  CACH 2 - nhan-sms-tu-dong-dien-thoai-adb.bat
    Dung khi muon doc SMS truc tiep tu dien thoai Android (khong can
    module SIM rieng) - CHUAN BI TRUOC 1 LAN:
    - So dien thoai chinh la PHONE_NUMBER ma GpsSmsSender.ino gui toi.
    - Cai "Android Platform Tools" (co adb.exe), them vao PATH.
    - Tren dien thoai: bat "Tuy chon nha phat trien" (bam lien tiep "So
      build" trong Cai dat > Gioi thieu 7 lan) > bat "Go loi USB". Cam
      day USB, bam "Cho phep" khi dien thoai hoi.
    Roi bam file .bat - tu chay het, khong can go gi them.
    CHUA KIEM CHUNG TREN THIET BI THAT (khong co san dien thoai/adb luc
    viet) - quyen doc content://sms/inbox qua "adb shell" khong can root
    NHUNG khong dam bao 100% tren moi may/ban Android (mot so ROM/Android
    moi co the chan). Neu loi "Permission denial" hoac khong thay tin
    nhan moi du dien thoai co, day la gioi han cua may/ROM do - dung
    Cach 1 (ESP32 NHAN) thay the.

  Ca 2 file .bat deu tu mo 1 cua so server rieng ("Nhan SMS - Server ban
  do") - CUA SO DO PHAI GIU MO trong luc cho nhan SMS, dong no la tat
  toan bo (dong cua so cua script doc SMS thi chi tat rieng duong doc do
  thoi, server + trang ban do van con). Dung ca 2 file .bat cung duoc neu
  co du 2 loai phan cung (vd 1 xe dung Cach 1, xe khac dung Cach 2) - ca
  2 deu day vao CUNG 1 server/trang.

  Neu muon tu chay tung buoc thay vi dung file .bat (vd de xem log ro
  hon): node nhan-sms-tu-dong-server.js, roi node doc-sms-qua-esp32-usb.js
  COM_x hoac node doc-sms-qua-dien-thoai-adb.js o 1 cua so khac.

DAT TEN THIET BI CHO SO DIEN THOAI (thay vi hien so tho tren ban do) -
tu 2026-09-03
=====================================================================
Tren trang ban do co nut "Thong tin thiet bi" - bam vao mo 1 tab moi la
trang danh ba so dien thoai/ten thiet bi (thong-tin-thiet-bi-tool.html). Dien so dien thoai + ten muon hien (vd "Xe
may 1"), du lieu tu luu va ban do se tu doi ten trong lan cap nhat vi tri
tiep theo - khong can sua code KNOWN_SENDERS/nap lai firmware nhu truoc.
Co the dien tay tung dong hoac bam "Nhap tu Excel (.xlsx)" de nhap hang
loat (cot 1 la so dien thoai, cot 2 la ten). Trang nay CHI dong bo len ban
do khi mo dung qua nut o tren (tuc la qua chinh server dang chay o
127.0.0.1:8899) - neu bam thang chay-thong-tin-thiet-bi-tool.bat (mo truc
tiep bang file) thi van dung duoc de xem/sua nhung chi luu rieng trong
trinh duyet do (pill "Chi luu tren may nay"), KHONG len ban do. Du lieu
danh ba nay duoc server GHI XUONG DIA (lam_viec/device-directory.json) -
KHAC voi lich su vi tri o duoi (chi giu trong RAM), vi day la cau hinh nen
song sot duoc qua lan khoi dong lai server.

GIOI HAN CAN BIET (them, rieng cho tinh nang nay):
   - nhan-sms-tu-dong-server.js chi giu LICH SU VI TRI trong RAM (giong
     vi-tri-server) - tat server la mat het, phai cho SMS gui lai. Rieng
     danh ba ten thiet bi (o tren) co ghi xuong dia nen KHONG mat.
   - Dinh dang dong "TOADO|..." (Cach 1) va cach parse "adb shell content
     query" (Cach 2) da duoc kiem tra bang du lieu gia lap, nhung PHAN
     CUNG THAT (cong COM that, dien thoai that) chua duoc kiem chung day
     du - neu gap loi, xem thong bao script in ra (deu co huong dan kem
     theo) truoc khi bao day la bug.

GIOI HAN CAN BIET:
   - Server khong luu lich su xuong dia - tat/khoi dong lai server
     la mat het vi tri dang co (chi con neu ai do da bam "Tai
     GeoJSON" truoc do).
   - Trinh duyet dung dinh vi + het pin/tat man hinh van co the tam
     dung GPS du da co Wake Lock (tuy he dieu hanh/trinh duyet).
   - Thiet ke cho quy mo "hang tram" thiet bi tren 1 server Node don
     le la thoai mai (tai rat nho: vai chuc ban tin/giay). Neu can
     quy mo lon hon nhieu (hang chuc nghin+), se can kien truc khac
